# Portfolio fonts

The portfolio hosts these Latin variable WOFF2 fonts locally, so typography does not depend on an external font request at runtime.

| Local file | Family and use | Weights | Source |
| --- | --- | --- | --- |
| `manrope-latin-variable.woff2` | Manrope: body text, navigation, labels and buttons | 200-800 | [Google Fonts specimen](https://fonts.google.com/specimen/Manrope), [downloaded font](https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggexSg.woff2) |
| `sora-latin-variable.woff2` | Sora: headings, names and profile statistics | 100-800 | [Google Fonts specimen](https://fonts.google.com/specimen/Sora), [downloaded font](https://fonts.gstatic.com/s/sora/v17/xMQbuFFYT72XzQUpDg.woff2) |

Both use the SIL Open Font License 1.1. The unmodified licence text is included in `Manrope-OFL.txt` and `Sora-OFL.txt`, obtained from the corresponding Fontsource variable-font package distributions:

- [Manrope licence](https://cdn.jsdelivr.net/npm/@fontsource-variable/manrope@5.2.8/LICENSE)
- [Sora licence](https://cdn.jsdelivr.net/npm/@fontsource-variable/sora@5.2.6/LICENSE)

The original WOFF2 files are unmodified. System sans-serif fallbacks remain available for characters outside the Latin subset.
